## 三、行为零变化的证法与实测结果

r34 用「`git show --name-only | grep -c "^site/"` ＝ 0」证生产未变；本件 `site/` 有改动，故另择证法。**不说「应当无影响」，给三层可复跑的证据。**

### 主证：去注释后逐字节相同（sha256）

**判据**：JS 注释与 HTML 注释都不参与执行/渲染，这是**语言级保证**，非观感判断。故若两版文件**剥掉注释后完全相同**，则改动必然全部落在注释内，行为零变化。

工具（一次性，置于 scratchpad，不入仓）：
- `strip_comments.js` —— JS 词法扫描器，正确区分字符串／模板串（含 `${}` 嵌套）／正则字面量／行注释／块注释，把注释字符替换为**等长空白**（行号列宽不变）；HTML 模式剥 `<!-- -->`。
- `compare_stripped.js` —— 丢弃纯空白行、其余行两端 trim（缩进与行尾空白不参与 JS 执行与 HTML 渲染），比对剩余行序列的 sha256 并逐行报差异。

**实测**：

| 文件 | 去注释代码行数（改前/改后） | 差异行 | sha256 |
|---|---|---|---|
| `site/app.js` | 4545 / 4545 | **0** | 改前改后同为 `1bf05aa81e3e3c2d3e9f7769b238134aaf18bb9edcadda42f20aec5999a0ad16` |
| `site/index.html` | 380 / 380 | **0** | 改前改后同为 `dd5ad566f02312236dd107decfa5d82d95166a0d9233a0d5cbce78583ce2ffde` |

**旁证（长度守恒）**：`site/app.js` 改后总长比改前 **+52** 字符，被剥的注释字符也恰 **+52**（29247 → 29299）；`site/index.html` 总长 **−2**，被剥注释字符也恰 **−2**（2079 → 2077）。**增减的字符与剥掉的字符一一抵消**，即净变化全在注释里。

### 工具自证：扫描器没把代码误当注释吃掉

若扫描器有 bug 误吞了一段代码，那段在两版里被同样吞掉，比对仍会「相同」——证明力就空了。故两道自证：

1. **语法自检**：`node --check` 跑改前、改后两份**去注释产物**，**均通过**。扫描器若吞了代码，语法必坏。
2. **反证（按类反证立断言）**：取改后的 `site/app.js`，只把 `const dotR = 10, dotGap = 44;` 注入为 `45`（一处真代码改动），再跑同一套比对——**当场转红且精确点名**：

```
差异 #1 行序 4082:
    改前: const dotR = 10, dotGap = 44;
    改后: const dotR = 10, dotGap = 45;
注入版对比｜去注释代码行数 4545 / 4545｜差异行 1
判定：✗ 不同 —— 有可执行代码被改
```

**即：这套证法能在「真改了代码」的版本上红。**（§7.2 判据）

### 佐证：diff 逐处目视 ＋ 全站行为门

- `git diff --stat`：`site/app.js` 17 行变动、`site/index.html` 4 行变动，共 **11 增 10 删**，`git diff -U1` 逐 hunk 核过——每一行改动的行首均为 ` * ` 或落在 `<!-- -->` 之内，无一行在注释外。
- 总门 `tools/qa/vision_r24a.js` 511 项断言覆盖全站渲染与交互，改后复跑 **511/0**，与改前基准一字不差。
