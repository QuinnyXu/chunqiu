## 一、做了什么

立 **`tools/build_kaodui_index.py`**（Python 标准库，560 行），从 `data/csv/` 五个源栏抽取核对台账，生成 **`docs/kaodui_index.md`**（1177 行，265 KB，**458 条**）。

**所对之症**（任务书〇节）：病根不是记录缺失，是记录不可检索。故本件之成算全在「一检即得」，不在表好不好看。据此定三事：

1. **抽取之单位取「段」**——源栏之文以 `【…】` 节标切段，节标即该条之「所核之项」。**一段之内有数证者（①②③ 之属）不再细切**，其书与页并列于一条——如此「三证同指一地」这句结论与其三证同见一行，一检即得（梁城之验即系于此，见 §四）。
2. **一条一行**——正表为 markdown 表格，一记录占一行，使 `grep`／Ctrl-F 一击即得全条，不必上下翻。
3. **另立「速查·按核对状态」**——把 458 条按证据状态倒排（本轮无从核 35／未见 16／未核待补 18／未核 49／待核 29／未取纸本 8／非纸本核对 11／须纸本核 6／待纸本 41／留痕待核 15／未标核对状态 6／纸本已核 58／扫描本已核 7／扫描本 32／电子本已核 9／电子本转引 34／电子本 57／转引 9／已核 64）。**「还有什么没核」自此可一目而尽**。

**生成物之性质**：文件头明书「本文件由 `tools/build_kaodui_index.py` 生成，勿手改」；**不入 `site/data/`**（裁八：公开与否本轮不定）。生成器**不取墙钟时间**，输出只系于输入，故同一份 `data/csv/` 必得同一份索引——首节列五个源 CSV 之 sha256 前 12 位为凭，`--check` 可验其是否与现文件一致。

**用法**：

```sh
python tools/build_kaodui_index.py            # 生成 docs/kaodui_index.md
python tools/build_kaodui_index.py --check    # 只验不写（不一致则 exit 1）
```

## 二、八目之抽法（每目之来历与其限）

| 目 | 何以得之 | 抽不出时 |
|---|---|---|
| 标的 | 表名·行 id·栏名（机械） | 恒有 |
| 所核之项 | 段之 `【…】` 节标**原文** | 「未标」 |
| 所据之书 | 段内 `《…》` 全称，及本库通用简称（杨注／谭图／杜注／孔疏／阮刻十三经注疏／整理者注释／整理本／维基文库）——**照原字留，不代展全名** | 「未标」 |
| 页 | 「页 N」「页 N–M」「N–M 页」「第三五二页」四式 | 「未标」 |
| 核对状态 | 词表匹配，十九档（见下） | 「未标」 |
| 核者 | 与核字语**相邻**之「站长／领队／Sophia／本库」 | 「未标」 |
| 日期 | `YYYY-MM-DD` | 「未标」 |
| 结论与其裁定出处 | 段内**着重段**（成对 `**` 之内）去其纯引注者，＋ `§N`／`v1.N`／`rNN`／`裁定 N`／归档件路径 | 空 |

第九栏**定位**（字符偏移＋首四十字）另立，以践口径三「索引是指路牌，不是替代品」。

**两条机械规则，非判断，特此明记以备复核**：

- **书与页之「就近后随」配对**——一书之后、下一书之前所见之页，归其名下；书前之页归「未标」之首槽。故一段之末书会吃进其后所有之页（如 `sources.B003.notes` @662 之《中国历史地图集》槽作「页26–27＋页24–25＋页29–30」）。此系规则之实然，定位俱在，读者可径回原文。
- **着重段即结论**——本库行文以成对 `**` 标其所欲立之断语，故取之为「结论摘」，去其含书名号者与纯页码者。摘而不断，逾 220 字者截并标「〔截，全文见源栏〕」。

**核对状态十九档，一律照本库自用之语命名，不新造、不并档**：
本轮无从核／未见／未核待补／未核／待核／未取纸本／非纸本核对／须纸本核／待纸本／留痕待核／未标核对状态／纸本已核／扫描本已核／扫描本／电子本已核／电子本转引／电子本／转引／已核。
**一段见数档者并列**（以「／」相连），抽取器**不代择其一**——一段本可兼记数事（如「页码纸本实见，而幅名未照目录核」）。

**〔否定／引述语境，须回原文〕之记号**：状态词前后见「不因…径称」「非」「须与…区分」「是两件事」之类语时加此记（全库 40 项、涉 36 条），示此处之状态词**可能系否定句或引述**（如「不因惯称相符而径称已核」）。抽取器**不代判其正反，既不径删亦不径信**——径删即藏，径信即假，故留记号而付读者。
