### 二之一、导览之记（任务书二节 1；领队加注一·4 判为「本件唯一可径落之改」）

**病**：`chunqiu_tour_v1` 自 r14 立起只记「见过与否」，而**唯一写入之处在 `endTour()`**——故凡未走完者不留记，下次再访导览又覆到地图上。

**治**（`site/app.js`）：
1. 键之值由一态改记 `{ v:1, step, done }`，**并在 `showTourStep()` 内逐步落记**（不俟收尾）；
2. `tourRead()`：旧值 `"1"`（r14–r53 所写）**一律读作「已走完」**；解析不出者同断为已走完——**宁可少弹一次，不可把读者的旧记当没有**；
3. `localStorage` 不可用（隐私模式）时仍断为已走完，与 r14 之 `tourSeen()` 同语义，不自动打扰。

**并补一条明路**（任务书二节 3「改后须仍有一条『第一次来该点哪里』之明路」）：`site/index.html` 之 `.home-extra` 首位增 `#home-tour-entry`，其文随所记之进度跑时写入——一无所记／已走完＝「初次导览 · 三步 →」；走到第 N 步未走完＝「继续导览 · 第 N 步 →」（点之自该步接上）。
★ **此按钮之存在不系于任何存储状态**。这不只是「不自动弹」之替代，还补了一个此前无人发现之缺：**旧版 `tourSeen()` 于存储抛错时返 `true`，故隐私模式下导览从不弹，而首页又无任何入口——那条路是彻底断的**（唯一入口在关于页深处之「重看引导」）。走查门【记·辛】专断此条，旧版当场红。

★ **其训**：**一个抛了错却不退的门，比一个红门更坏**——红门在说话，挂住之门什么也不说，而调它的人只能等。
