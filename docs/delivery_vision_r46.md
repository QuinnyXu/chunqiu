## 2. 转换规则的实际实现与限域判据落点

**限域判据（依领队 ⚑C 之裁：取层标）**，落点在 `site/app.js:951`：

```js
const inScope = caveat.indexOf(DIPLO_SCOPE_MARK) >= 0;   // DIPLO_SCOPE_MARK = "丙档·照录括注式"
```

`caveat` 是既有 `splitCaveat()` 从 `modern_note` 首段 `【…】` 取出的编者层标，本件复用之，未另造一套解析。**未取 `quote_type`**——理由已写进代码注释：`quote_type` 答的是「材料属哪一层」，不是「本行括注是不是整理本回改」，而现网二者恰好只差一行，那一行正是会被压坏的 `Q167`。层标判据另有一利：此后凡 Sophia 依丙档体例落层标之行，**无须改前端即自动入域**。

**转换式**，`site/app.js:930`，取 Sophia 实测可行之条，一字未改：

```js
const DIPLO_UNIT_RE = /(?:[㐀-鿿]＝)*[㐀-鿿]?（([^）]+)）/g;
```

实现上未用 `String.replace` 直接出字符串，而是 `diploParts()` 把原文**切成「素文／可换段」序列**，可换段同时持两形入 DOM，靠 CSS `display` 二选一。这样做是为满足「原貌须可复制」：`display:none` 的文本不入选区，**当下所见之形即选中所得之形**，原貌不是 `title` 那种「看得见取不到」的东西（实测见 §3 之选区断言）。

**默认态之分寸**：默认通行字；经回改之处带**虚点下划线**（层色 `--excav`）留痕，读者看得见「这几个字动过」；两条通往原貌之路——悬停单段就地换形（鼠标）、点「释文原貌」钮整段换形并保持（键盘／触屏／读屏，可选可复制）。

## 4. 浏览器实渲实况（fix44c §7.1 乙所留之界，至此销掉）

此前 Sophia 与 Skipper 两侧皆数据侧静态实测、未启浏览器。本件真开 Chromium（Playwright 1.62，Windows 11）实测：

**字形覆盖**——判据不取猜测，取 CDP `Accessibility`／`CSS.getPlatformFontsForNode` 与位图栅格化两路对读：
- 落地字体：「＝」(U+FF1D) → **SimSun**；「（）」(U+FF08/09) → **SimSun**；对照汉字「息」→ **SimSun**。**三者同落一支字体，未回退**。实测字体栈 `"Songti SC", "Noto Serif CJK SC", STSong, SimSun, serif`，14.4px，字距 0.72px。
- 推进宽：＝ 14.72px／（） 14.72px／息 14.72px——**全角推进宽，与汉字等宽**，未落半角形，行内不塌；基线同行、行高未被撑开。
- **豆腐之判须留一句实话**：推进宽在 CJK 字体里辨不出豆腐——SimSun 的 `.notdef` 方框**也是全角**，且 CDP 连必缺字 U+FFFE 都报作 SimSun（四者推进宽俱 14.72px）。故改取**位图实证**：同字体同字号栅格化后比对墨迹签名，「＝」与「（」「）」的位图**均异于 U+FFFE 的空心方框**，亦互不相同——真有字形，非豆腐。（首版断言用的正是那条无效的宽度判据，实测当场红；这是走查脚本自己的毛病，已改判据、未松口径。）

**窄屏换行**——320／360／390／680px，通行字态与原貌态各测一遍，四档八测**可换段无一被拆行、页面无横向溢出**。
- **此处有一处真发现，且是本件独有的**：`「賽＝（息）」` 这类单元**确会被拆行**。UAX#14 保得住「（息）」不拆（括号前后不断），**保不住「賽」与「＝」之间**——全角等号是 ID 类，与汉字之间可断。对照实测（临时去掉 `nowrap` 再量）：**320px 通行字态下 `賽＝（息）`／`賽＝爲＝（息媯）`／`訓（順）` 三处俱断**，390px 与 680px 原貌态下 `訓（順）` 亦断。断在此处，读者见到的是「一个碎掉的符号」而非一处校读。
- **回退方案已内置并实测生效**：`.q-seg { white-space: nowrap; }`。现网最长可换段为「賽＝爲＝（息媯）」8 字，320px 实测不溢出。
- 若他日有更长的可换段而窄屏溢出，回退之回退是把 `nowrap` 换成 `word-break: keep-all` 或只对含「＝」者施 `nowrap`——**现网无此需要，不预写**。

**缺字回退方案（现网未触发，备而不用）**：现网 Windows/SimSun 下「＝」与全角括注字形俱全，无须回退。若他日在缺 CJK 全角标点的环境上缺字，建议之序为：①在 `--serif` 栈里补一支覆盖全角标点的免费衬线（须走预生成静态资源、不引 webfont 网络请求，红线 6）；②退而对 `.q-seg` 内的「＝」加一条 `font-feature`／`font-variant-east-asian: full-width` 之类的本地兜底；③再退则**只在原貌态**把「＝」以 `::after` 之类替为同义可用之符——但**那已是改字之形，须先报站长**，本件不预设。

**交互与无障碍实测**（§6／§11）：切换钮触摸目标 70×26px；键盘可 Tab 可获焦、Enter 生效、可逆；无障碍树内 `role=button`、`aria-pressed` 两态俱正确暴露、两态**可读之名一致**（写死在 `aria-label`，不随按钮字面变，免得读屏者听成两个控件）；原貌态下「賽」与「＝」确已可及——**读屏者亦取得到原貌**；整条引文只占 **1 个 Tab 位**（可换段不各占一位，否则越过一句话要按四次）。
