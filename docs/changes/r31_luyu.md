## 0. 体例与口径

### 0.1 页码引注末缀二式（本轮新增「同次核」一式，请领队核可）

任务书裁定「尾缀保留，且照同前核体例书写」，即沿用 r30 九处之形态：

```
（**纸本，站长核对**，2026-08-04；页 389，页码 2026-08-13 补核）
```

该形态之所以并存两个日期，r30 §0.1 已写明理由：**2026-08-04 是站长核对正文用字／落点之日，2026-08-13 是站长核对页码之日，两次核对时点确实不同**，并存方能经得起「到底是哪一次核的」这一追问。

**本轮新回填之四处（`L_YU` 谭图、`L_SHOUZHI` 谭图、`Q344`、`Z102`），落点与页码同出站长本次一次复核**，并无两个时点。若机械照抄成「页 24–25，页码 2026-08-15 补核」，则等于凭空断言存在过一次「另行补核页码」的动作，与该尾缀设立的初衷（标注要经得起追问）恰好相反。故本件取**从实之变体**，形态对齐而语义从实：

```
（**纸本，站长复核**，2026-08-15；页 24–25，页码同次核）
```

即末缀二式取一：**另次补入页码者作「，页码 YYYY-MM-DD 补核」**（r30 九处属此）；**页码与正文用字同出一次核对者作「，页码同次核」**（本轮四处属此）。此式已写入 §7 拟入 conventions 之条文，请领队核可。**本件不自行简省、亦不自创第三式。**

**误在哪里**：盂是**宋地**，本不当于楚吴越幅求之。r27c 的动作没有错（确实核了纸本），错在**核的是不该核的那一幅**，而这一层「核了哪一幅」当时未曾留痕——直到 r30 因页码对不上而暴露矛盾，才被站长复核揪出。这正是 §7.3 拟立「有界扫描留痕纪律」的直接起因。

### 2.2 为什么不把它写成「一直有落点」

站长原话之意已采入行内：「r27c 曾据楚吴越幅报未标，r30 站长复核郑宋卫幅实有落点」。**依据链的错误史也是依据链的一部分**——抹平之后，后人无从知晓这条判据曾错在哪里、又如何被纠正，也无从判断同型错误是否仍潜伏于他处（本件 §3 的扫描清单即是对这一问的回答）。故 `coord_basis` 中专设一节【★依据链之反转，如实记录不抹平】，与依据链本身并列，不藏于末尾。

### 2.3 坐标微调（照 `L_BOJU` 先例的手法与精度口径）

先读 `L_BOJU` 那一行怎么做的，跟着做——其手法有三层：① 写明**取点之实**（「坐标取今湖北麻城市治概位」）；② 写明 **§4 公式回校结果**（`x=707、y=569，在覆盖范围内`）；③ 写明**精度自限**（「所定仍是『麻城境』这一县域范围而非某一具体战地，坐标只作县治概位」）。本件照此三层办：

| 项 | 旧（r30 及以前） | 新（本轮） |
|---|---|---|
| `lat`／`lng` | 34.45／115.05（睢县县治概位） | **34.50／115.02**（睢县**西北**一带概位） |
| §4 回校 | x=709、y=315 | **x=707、y=311**（在覆盖范围内） |
| 位移 | —— | 约 7.7 公里，方位西北；投影上 (−2, −4) 像素 |
| 精度自限 | 「睢县境概位」 | 「**睢县西北**」是方位泛指而非盂之确址，仍只取本库两位小数之县级概位，**不据「西北」二字自造精度** |

回校数值由脚本按 conventions §4 公式实算（`x=(lng−105.0)/17.0*1200`、`y=700−(lat−29.5)/9.0*700`，标准四舍五入），非手算。

### 2.4 `certainty` 升否 —— 本项经站长明确授权由 Sophia 判：**维持 `medium`，不升 `high`**

站长给出的正证有二（谭图落点 ＋ 杨注僖公二十一年引《大清一统志》「睢县有盂亭」，页 389），确为**双正证**。判不升之理由三条：

1. **双正证所证者是县域级对应，非确址**。二者合起来证成的是「盂在睢县一带（且在县西北）」，而本行 `modern_location` 自书「确址无考」；conventions §5 定 `high` 为「可作骨架直接使用」，与「确址无考」之自述隔着一间。
2. **循本库既有尺度，不当越过 `L_BOJU`**。柏举得谭图＋杨注＋江永**三家**合流，仍止于 `medium`，其行内明书「未升 `high`，因所定仍是县域范围」。盂之证据为**两家**（谭图、杨注引方志），不厚于柏举；若本点升 `high` 而柏举止于 `medium`，本库三级标注在两点之间即自相矛盾——三级标注的价值全在**同尺度**，破一次即不可信一次。
3. **反转所改变的是依据，不是档位**。本轮消去的是「优先序第一位无落点」这一**负项**，其效果是让既有的 `medium` 坐得更稳（此前 `medium` 是一正一负相抵而得，如今是双正而无负），而不是把它推过 `high` 的门槛。宁降不虚。

**附一句反面提醒**（照 r30 §5 第 4 条之例）：本行两个字段此后不得因「依据链已完整、页码已补齐」而被顺手升级——依据链完整与否，和它证到了哪一级，是两件事。

### 7.1 落点：§7（私有层与叙事分层）——附于「通例（v1.26）·二手引述须标核对状态」条**之末**

> **页码引注写法（v1.**〔下一号〕**新增，r31 定案）**：注文中引二手文献而附页码者，一律作「**页 N**」（如「页 1534」「页 24–25」，连页用起讫号 `–`），**不作「第 N 页」**。此式自 r30 页码回填件起于全库统一施行，r27c §7 回填示例所用「第 N 页」一式此后不再使用（既有归档文书依 §10.1 不回改）。页码之核对状态并入本条所定之核对状态串，**末缀二式取一**：① 页码系**另一次核对**补入者，作「**，页码 YYYY-MM-DD 补核**」——两个核对日并存，以免读者误以为页码亦出正文核对之日（r30 九处属此）；② 页码与正文用字／落点**同出一次核对**者，作「**，页码同次核**」（r31 四处属此）。不得于二式之外自创第三式；亦不得在只有一次核对时机械照抄第①式，那等于凭空断言存在过一次并不存在的补核动作。**本条关闭 §11 待决之「页码写法体例确认」与「尾缀去留」两项。**

### 7.2 落点：§7 —— 新立一条通例（紧接上条）

> **通例（v1.**〔下一号〕**新增，r31 立）·判定反转须如实记录，不得抹平**：某点／某条之依据链，若因先前查检有误而发生**反转**（负证改正证，或反之），须在该行注文中**如实记录反转全过程**——原判为何、所据为何、误在何处、何时由谁复核推翻——不得径改写为「一直如此」。理由：**依据链的错误史也是依据链的一部分**；抹平之后，后人无从知晓该判据曾错在哪里、又如何被纠正，更无从判断同型错误是否仍潜伏于他处。**首例**：`places.L_YU`（盂）——r27c（2026-08-04 纸本核对）据**楚吴越幅**报「谭图该幅有睢县而未标『盂』」，据此否定性依据判两个 `certainty` 双双不升级；r30 站长复核**郑宋卫幅**（第一册页 24–25）**实有「盂（唐盂）」落点，在睢县西北**——原「未标」系误查楚吴越幅所致（盂是宋地，本不当于楚吴越幅求之）。r31 据此整段改写 `coord_basis`，`coord` 微调至睢县西北（34.50／115.02，手法照 `L_BOJU` 先例），`coord_certainty` 由 `low` 升 `medium`，`certainty` 经站长授权由 Sophia 判为**维持 `medium` 不升 `high`**（双正证所证者为县域级对应，且不当越过同尺度之 `L_BOJU`）。**并记一处更正**：v1.26 版本记录所立通例「差别不在核对做没做，而在核对到了什么」**通例本身仍立**（本次恰为其又一应验：核对到的是「查错了幅」），惟其**举例**——以 `L_YU` 为「核对到无落点」之例——**已失据，此后不得再以 `L_YU` 为该通例之案例**；归档文书与历史版本记录依 §10.1 不回改，本项更正之正式落点即本版记录。**本条关闭 §11 待决之「`L_YU` 谭图页码待补」项。**

### 7.3 落点：§10（协作节奏：备料与合入分离）——新增小节 **§10.2**

> ### 10.2 有界扫描的留痕纪律（v1.**〔下一号〕**新增，r31 立）
>
> 凡任务书划定范围令「逐一对照」者（如「落于某图幅范围内的低置信地点」），**对照结果须完整留痕，不得只列有改动者**：查过而未动的条目同样逐条列入该批 `CHANGES.md`，并注明未动之由（**不在范围** ／ **范围内但本库无新证** ／ **本轮无从核**）。理由有二：① 下一轮不必重查；② 使「查过」与「没查」事后可分辨——r27c 之误（据错幅报「未标」，并据以立判据）正因「究竟查的是哪一幅」未曾留痕，直至 r30 因页码对不上才暴露。
>
> **自限一条**：备料者本人无纸本／可靠电子本者，一律记「**本轮无从核**」，**不得以推理代核对**，尤不得写成「查无落点」——那是把消极的「没查到」写成积极的「不存在」，与 §7 v1.26「二手引述须标核对状态、未核者不得作断言语气」是同一道防线。范围边界不明者（如某点是否落在该幅图面之内）另标「幅界存疑」，一并留痕待核。**首例**：r31 郑宋卫幅有界扫描，50 点全集分四组尽列（甲组 23 点在幅、改 2 不动 21，乙组 27 点不在幅只记不动），并留下 21 点的现成待核清单。
