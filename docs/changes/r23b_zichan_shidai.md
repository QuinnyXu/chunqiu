### 1.1 逐条依据与取舍

- **E188（前565）**：《左传·襄公八年》「郑人皆喜，唯子产不顺」一段。取为线首，因这是子产见于《左传》的第一条，且其言当年即验（冬楚子囊伐郑讨其侵蔡，郑遂从楚）。该讨伐之役本库未单立事目，只在 summary 记其应验，不另占配额。
- **E189（前563）**：《左传·襄公十年》西宫之难。子产之父子国死于此难，是其人物线的转折；传文详列其「为门者、庀群司、闭府库……兵车十七乘」的处置次第，与同段子西「不儆而出」相形，为《左传》写子产才具的第一处正笔。同年焚子孔载书一节（「众怒难犯，专欲难成」）并入本条作 Q238，不单立。
- **E190（前549）**：《左传·襄公二十四年》寓书范宣子。取之因这是子产**执政前**对晋外交的第一次经典发言，与 E194（执政后当面抗辩）构成一组对读；且「德，国家之基也」为其政论之纲。
- **E191（前548）**：《左传·襄公二十五年》。**方向订正见 §6 第 3 点。**
- **E192（前543）**：《左传·襄公三十年》伯有之乱。立此条有两个必要：① 它是子皮授政（E193）的直接前因（伯有既死而后授政）；② 子产「枕之股而哭之」礼其仇尸、子皮「杀有礼，祸莫大焉」怒止驷氏之攻，是子产—子皮关系（R245/R246）的成立依据。
- **E193（前543）**：《左传·襄公三十年》授政、为政之制、舆人两诵。分类取**政制**（都鄙有章、田有封洫、庐井有伍是国家机器本身的构造，非礼俗层），依 conventions v1.21 §3「政制」与「礼俗」的分野。襄公三十一年「子皮欲使尹何为邑」一段系年晚一年，作 Q247 挂本条并置对读、不另立事目——理由：该段的落点是「子皮以为忠，故委政焉，子产是以能为郑国」，是授政一线的收束句，单立会把一条关系拆成两个半截；系年之实已在 summary 与 Q247 的 modern_note 中写明，`source_ids` 因此兼列 `Z084`。
- **E194（前542）**：《左传·襄公三十一年》。落点取**晋都绛**（史文明书「子产相郑伯以如晋」）。
- **E195（前542）**：《左传·襄公三十一年》。分类取**政制**——乡校议政之存废是"如何听政"的制度选择，非一时之礼俗。仲尼评语分条作 Q252（评论层），**十岁问题见 §6 第 1 点**。
- **E196（前536）**：《左传·昭公六年》。分类取**政制**（依任务书，亦合 v1.21 §3 定义）。叔向书择要作 Q254、子产复书作 Q255，两者对读是本条的核心价值；士文伯占辞另作 Q256 并注明"本库不据以为因果"。
- **E197（前524）**：《左传·昭公十八年》为主、昭公十七年为前事。**两年合一事目系依任务书口径**（任务书作「昭十七—十八，前524」），系年取火作之年前524，前525 冬裨灶之预言作 Q257 挂入、`source_ids` 兼列 `Z086`，编年之实已在 summary 与 Q257 的 modern_note 写明。reliability 仍 `high`（两年皆经传明文，非推算）。若领队认为应拆为两条事目（昭十七「星孛与裨灶之请」、昭十八「四国皆火与拒禳」），本件留有 E200 之后的号段，拆分不困难——**列为可选改排建议，不自行裁量**。

### 2.2 孔子入库口径（**本件自查重点**）

依任务书裁定 3：**以《左传》明文事件的配角身份入库，不升主角，不提前展开。** 落地情况：

   - 该条**如实著录、不删**（它是"不毁乡校"这一必收事目在《左传》中的固有构件，删去反而失真）；

   - `P_KONGZI.notes` 与 `E195.summary` 两处均把年龄核算写明。
   - 换言之：**孔子入库的"首条"在编年顺序上其实是 E195（前542）而非 E199（前522）**，与裁定 3 的字面表述有出入。本件按"史文所至、如实著录"的裁定精神处理（既不为迁就表述而删条，也不含糊其在场性质），**如领队认为应另作安排（如 E195 只留记事、仲尼语并入 E199 的注），请裁示，本件不自行落定为惯例。**
