## 2. ★ 自查重点一：鞭平王尸的处置（判为 passage，不单立专条）

任务书列此为「本批第一分层示范」并许「专条或 passage 你判」。**本件判为：不单立事目，作 Q377 挂靠 1a 所立之 E228（柏举与入郢）**，另配 Q378（《史记·吴太伯世家》同事异文）对读。三条理由，按分量：

1. **《左传》之无，是详载中之无**。《左传·定公四年》于吴入郢之后详叙：「以班處宮」、夫概王与子山争令尹之宫、左司马戌之死（句卑剄而裹之）、楚昭王涉雎济江入云中遇盗、王孙由于以背受戈、奔郧、鬬辛止其弟之弑、奔随、吴人告随人「周之子孫在漢川者，楚實盡之」、随人卜而辞吴、子期以身代王——**如此详密而独无鞭尸一节**。这与一般的「传所不载」分量不同：不是简略而漏，是在同一处、同一时段的密集记载中缺席。
2. **《史记》内部三处互异，是其为传闻之内证**。《伍子胥列传》作伍子胥一人「掘楚平王墓，出其尸，鞭之三百」（Q377）；《吴太伯世家》作「子胥、伯嚭鞭平王之尸以報父讎」（Q378）——鞭者一人抑或二人、掘墓与否、有无「三百」之数，同一著者同一部书而三事皆异。
3. **本库既有裁定之类推**。conventions §11 已裁定「**不为著名但仅见后出层的情节开单独展示位例外**」（E130 绝缨之宴），理由是「若为知名度高开例外，等于让展示需求反向侵蚀数据分层的判据」。鞭尸之于 `events`，与绝缨之宴之于 `events` 是同一形态——极著名、仅见后出层、经传详载而无之。

**须诚实登记的代价**：`events` 表有 `reliability` 字段（`places` 无），技术上本可单立一条 `reliability=low` 的 S 层事目，读者亦能分辨。故本件之判**不是唯一可行解**，而是在「可分辨」与「不并列」之间取后者——一旦立目，它便与柏举、入郢在同一条时间轴上并列，事目之「存在」本身即是一种断言，而 §11 裁定所守正是这一点。**请领队复核**；若裁定改立专条，本件所备之 Q377／Q378 两条引文与层标可直接移用，只需新增一行 `events`（建议网段 E245）。

引文与层标已就位：Q377 层标含上列三条理由之全文，Q378 层标逐点对读三处异同并申明「**分层不是整段弃置，而是逐句核其有无**」——同篇「五戰」「昭王奔鄖」「與鄖公奔隨」诸节与《左传》相合，独鞭尸一节无征。

## 3. ★ 自查重点二：「过昭关一夜白发」——**核出裁定 3 所记之出处有误**

裁定 3 原文列「过昭关一夜白发（《吴越春秋》T）」为本批分层示范点之一。**经核，《吴越春秋》无此文。**

### 3.1 三书逐一核对结果

| 层 | 书 | 昭关一节之实际文字 | 有无「白发」 |
|---|---|---|---|
| 经传 | 《左传·昭公二十年》 | **只「員如吳」三字**，行程一无所书 | **无** |
| 后出 S | 《史记·伍子胥列传》 | 「到昭關，昭關欲執之。伍胥遂與勝獨身步走，幾不得脫。追者在後」（另有渔父渡之、赠剑不受、中道乞食） | **无** |
| 说部 T | 《吴越春秋·王僚使公子光传》 | **「到昭關，關吏欲執之，伍員因詐曰：『上所以索我者，美珠也。今我已亡矣，將去取之。』關吏因舍之。」——诈言美珠而脱** | **无** |

《吴越春秋》该篇（该事所系之篇）已就 ctext 全文逐字核对：全篇「髮」字仅一见，为伍员至吴后「**被髮**佯狂，跣足塗面，行乞於市」，非须发变白；「白」字四见，无一涉发。该篇敷演之详为三书之最（有渔父之歌「日月昭昭乎侵已馳」、渔父覆船自沉、溧阳击绵女子饷之而自投瀨水诸节），**连它都没有白发**。

### 3.2 「一夜白发」之实际层级

今所传情节的要素——**东皋公**、**皇甫讷代过关**、**一夜愁白了头**——见于明代小说《东周列国志》第七十二回一系（本轮网络检索所及之百科条目亦径以「中国民间传说故事」立目）。**属小说层。**

本库九个来源前缀（Z/S/G/A/P/B/Y/L/T）中，`T` 之定义为「**先秦诸子及秦汉说部层**」（conventions §2），明清小说不在其内。故本件处置：**不建来源行、不作 passage、不引其文**，只在 `E243.summary`【★「員如吳」三字】一节与 Q370 层标中登记其层级与出处，使读者可按图索骥而不致误以为有古书依据。

### 3.3 这一核订反而让示范更锋利

原计划的示范是「传无而 T 层有」（两层）；实际是**四层**：

> 传只三字 → 《史记》有昭关、渔父、乞食 → 《吴越春秋》有诈言美珠、渔父之歌、溧阳女子 → **而最著名的「一夜白发」，三书皆无，出于明代小说**。

即：**最广为人知的一个细节，其层级比本库分层体系的最低一层还要低。** 这比原设想的示范更能说明分层之必要。已在 `E243.summary`、Q370 层标、`P_WUYUAN.notes` 三处写明。

## 4. 裁定 8 复核两项

### 4.1 《左传》「不名吴都」全帙穷检 —— **已完成，结论已回写 `docs/kaoding_wudu.md` 附记**

**方法**：ctext 本轮间歇不可达，改由**维基文库《春秋左氏傳》十二公卷全帙下载至本地作离线穷检**（隱桓莊閔僖文宣成襄昭定哀，约 25.3 万字，含经与传），字符串全文匹配，非抽样。

**结果一（候选专名零命中）**：姑蘇 0、姑胥 0、句吳 0、勾吳 0、梅里 0、闔閭城 0、吳都 0、干隧 0、延陵 0；「吳城」1 处经逐字核出为《哀公九年》「秋，**吳城邗**，溝通江淮」——「城」是动词、「邗」是地名，**非「吴城」一名**，排除。**故 §0.3 字面结论成立。**

**结果二（★ 对原论据的修正，须领队过目）**：穷检同时扫出本文件原未虑及的事实——**《左传》以专名书都者本是少数**：楚书「郢」26、晋书「絳」36／「新田」2／「翼」21、卫书「朝歌」8／「楚丘」10／「帝丘」3、宋书「商丘」2；而**齐（臨淄）、鲁（曲阜）、郑（新鄭）、陈（宛丘）、蔡（上蔡）全帙皆 0**。即「不名其都」并非吴国独有，是《左传》书都之常法之一种。

考订文档 §0.3 原文「这是吴都与晋都在证据处境上的**根本差别**」一语因此失之过强，**须收窄**——但**结论不动摇**，理由已写入附记：① 对齐鲁郑陈蔡而言「传不名其都」不构成问题（五国之都今地无争议、各有故城遗址，其中三处已在本库 `archaeology` 表内）；② 唯独对吴而言这一空白是决定性的——**同一种沉默，落在无争议之国是无害，落在四说相争之国是致命**；③ §2.2 五项立点前提的对照表不受影响（该表所比者是「迁徙有无经传明文」「迁入地望能否由经传自证」两项实质条件，与「是否以专名称都」是两个问题，原文把二者揉为一句是行文之失）。

**结果三（新得的正面旁证）**：《春秋·定公四年》「庚辰，**吳入郢**」与《春秋·定公五年》「**於越入吳**」——同一部书、相邻两年、同一句式：楚都有专名可书故书「入郢」，吴都无专名可书故只能书「入吳」。同类者《左传·哀公二十二年》「越滅吳，請使吳王居甬東」，灭其国、迁其君而终篇不着其都名。**此条本文件原未收，是本次穷检的实质收获。**

### 7.1 ★ R276 的 label 用字：**从传文作「復」，不作「覆」**

任务书原文写「伍员—申包胥知交而立场相对——『**子能覆之**，我必能兴之』，label 是文眼」。经双本核对（ctext 与维基文库《春秋左氏傳·定公》整理本），**《左传·定公四年》两本皆作**：

> 初，伍員與申包胥友。其亡也，謂申包胥曰：「我必**復**楚國。」申包胥曰：「勉之！子能**復**之，我必能興之。」

- 「覆」字出**《史记·伍子胥列传》**（「我必**覆**楚」），且《史记》申包胥之答作「**我必存之**」而非「我必能興之」——**任务书所引之句实为两书文本的混合**（「覆」取自《史记》、「我必能興之」取自《左传》）。已在 Q375 层标逐点对读。
- 传文「**復**」当读为「覆」（倾覆）之义：与下文「**興**」对举——你能覆亡它，我必能复兴它；杜预注训「復，報復也」，后世遂多径写作「覆」。**《吴越春秋》所记同一约作「子能亡之，吾能存之；子能危之，吾能安之」（Q371），以「亡」「危」对「存」「安」，正可为「復＝覆」之训作旁证**——是分层不等于弃置的一例（T 层材料不入骨架，但可为传文之训作旁证）。
- 本库处置：`quote_original` 与 `rel_label` **一律照录传文本字「復」**，训义写入 Q372 层标与 R276 之 `source_note`。**上报见 §9.1。**

传明书「伍員與申包胥**友**」，故 `rel_type` 取「师友」、`reliability` 取 high。二人立场相对是其关系之内容而非另一种关系——现行八类无「友而敌」一目，若另织敌对边，则同一对人物两边并列、互相抵销，反失「一覆一兴而终身为友」之实。故**只织一边，立场相对写入 `rel_label`**。
