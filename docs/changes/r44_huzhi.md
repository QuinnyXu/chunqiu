## §6 · 附注（写作向与体例备忘，**不入公开数据表**）

- 莘案是本库第一处「**查过，然后发现没事**」被正式写进两侧注文的案例。此前的体例默认「无异则无话可说」，而实情是：读者在《左传》一侧看到「敗蔡師于莘」，永远不会知道这个「莘」字曾被怀疑、被拿去和一枚战国竹简对过、又因为一次纸本扫描而确认为虚惊。**把虚惊也记下来**，与「依据链留错误史」是同一件事的两面——一面记走错的路，一面记走对了却无人知道的路。
- 婢案与莘案并列成一课：同一个转录本、同一部书，第五章「新」是错的（转录本改字），第六章「婢」是对的（偶合），第六章「牙」又是错的（整理本正读作「與」）。三处合观，口径句「转录本不可证某字作某」才立得住——**它不是说转录本总是错，而是说你无法预先知道它这次对不对**。
- 本件四行注文互相指路，读者从骊姬页或息妫页任一处读入，都能走完整条依据链而不必回到 `docs/`。这是「界面不写死库存数、注文自成索引」的一次实做。
