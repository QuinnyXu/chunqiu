**★ 先勘任务书一语**（只记，不改任务书）：发件文作「本事《左传》载『赵盾弑其君』而《史记》作赵穿弑」。实读：《左传》之**记事**亦书「趙穿攻靈公于桃園」，「趙盾弒其君」是**经文与大史所书之辞**（书法）；《国语》亦书「趙穿攻公於桃園」。故二叙于「谁动手」无相抵，其异在**「弒」字归于谁**——《左传》之书法归赵盾，《史记·赵世家》以「弒」直系赵穿（「趙穿弒靈公」），《晋世家》作「趙穿襲殺靈公」并借赵盾之口书「弒者趙穿」。
