### 1.1 逐条取舍与依据

- **E207（前556，配额内自主增补，如领队认为溢出可径行裁撤）**：《左传·襄公十七年》「齊晏桓子卒，晏嬰麤縗斬……其老曰：『非大夫之禮也。』曰：『唯卿為大夫。』」立此条有二由：① 这是晏婴见于《左传》的**第一条**，不立则晏婴线凭空起于前548 哭庄公，其人物线缺首；② 「唯卿为大夫」是其守分不僭之操的最早一笔，与 E208 辞邑、E209 辞更宅同一脉络，三条共成「辞受有节」一线。分类取「礼俗」（丧服等差之争，属仪节层）。
- **E208（前545）**：《左传·襄公二十八年》。事在庆氏亡后齐分其邑，传文以四人受邑之别（晏婴全辞、北郭佐尽受、子雅辞多受少、子尾受而稍致）并列成文，晏婴独全辞。分类取「礼俗」（辞受之节），非「政制」——「幅利」是自处之义，不是国之制度。邶殿在齐东鄙，**晏婴辞而未受，其地不构成事目落点**，故不为之立 `places` 行（§7）。
- **E209（前539）**：《左传·昭公三年》「初，景公欲更晏子之宅……景公為是省於刑」，并「及晏子如晉，公更其宅……使宅人反之」一节。**系次说明**：传文以「初」字发端，明标其事在如晋（E210）之前，故本库 `sort_key` 取 10、列于 E210 之上；如晋归而毁宅一节系时虽在如晋之后，仍与「初」字前事共成一事，作 Q289 挂本条、不另立事目。**分类取「政制」**：事之落点在「景公为是省于刑」——刑之繁省是治国之制，与 E196（郑铸刑书，主表已归「政制」）同类；若领队认为谏刑之事仍宜归「礼俗」，本条可径改，本件不自行论定为惯例（§6 第 4 点）。
- **E210（前539，共用事件）**：《左传·昭公三年》。两番季世之论对举成文，晏婴言齐将归陈氏、叔向言晋公室将卑。**二语皆预判之辞、非记既成之事**（田氏代齐与晋六卿专政均在其后，且晚于本库年代下限），Q291/Q292 层标已就此写明，`summary` 亦复述一句。落点取晋都 `L_JIANG`，**新田问题见 §6 第 1 点（上报，不自行改点）**。
- **E211（前522）**：《左传·昭公二十年》齐侯疥遂痁一节。**系次订正（本件自查纠错，见 §8.2）**：本条在传文中位于「十二月，齊侯田于沛」**之前**，故列于 E212（遄台论和同）之上，`sort_key` 取 30；本年无独立系月之文，`season_month` 从阙。分类取「礼俗」（祝史祭祀之争为事目表层），而实效在宽政薄敛（Q295），已于 `summary` 与 Q295 注中写明，读者不致误以为本条只是祭祀之争。importance 取 2。
- **E212（前522）**：《左传·昭公二十年》遄台之对。**`reliability` 依任务书取 `high`**（经传明文，本即 high，无推算成分）。系月：传文次序在「十二月，齊侯田于沛」之后，故系于冬十二月，`sort_key` 40。分类取「其他」——「和如羹焉」是论君臣进言之道的政论，非制度建置，不入「政制」；现行 16 类无「政论/记言」一目，与 E188（子产谏侵蔡之喜）同例归「其他」。
- **E213（前516）**：《左传·昭公二十六年》齐有彗星一节。分类「灾异」，importance 2。与 E211 同为「祸福在德、不在祝史鬼神」之论，相距六年；亦与主表 E197（子产拒禳火）为同时代同路数两处正笔，已于 `summary` 中互见。
- **E214（前516）**：《左传·昭公二十六年》路寝之对。**分类取「政制」**：晏婴指出陈氏厚施将得国后，对策不在削陈氏而在「唯礼可以已之……家施不及国，民不迁，农不移……大夫不收公利」，是国家名分制度之事，与丧祭仪节之「礼俗」非一层（Q300 层标已就此分辨）。**此为本件两处分类判断中较可争议的一处，列 §6 第 4 点待复核。**

## B1. **events 零新增**：T 层不得单独立事件之禁，本件适用，照办并说明

任务书给本件 **events ≤2** 的配额，并要求「按 conventions §7 挂靠通例处理（可立条则立、不可立条则挂 passage）」。逐条核过，**两组材料均属「不可立条」，故本件 events 实占 0 条，配额未用**。这不是遗漏，是规则适用的结果：

- **判据一（§2 T 层分层纪律，裁定4）**：「**不得单独立事件骨架**——`T` 类史料只作为已有经传骨架事件的旁证摘录挂入 `passages`，**不得仅凭诸子/说部材料新建一条 `events` 行**」。晏子使楚二章与二桃杀三士，《左传》《国语》《史记》**全无一字**，无任何经传/考古佐证可与之并立，纯为 T 层孤证。
- **判据二（§7 无系年材料挂靠通例）**：三篇俱**无系年**——使楚二章不著楚王之名（后世指为楚灵王系附会），二桃杀三士亦不系年不系月。即便退一步不论 T 层之禁，依 §7 通例亦当挂靠而不单立。
