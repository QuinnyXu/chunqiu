**补录**：新增 `Q379`（挂 E223，`quote_type=原文`），录《豳》《秦》《魏》《唐》《陈》及「自《鄶》以下，無譏焉」，用字与断句基准取**杨本／《春秋左传正义》十三经注疏本系统**。至此观乐评语四条完整无留白：`Q333`（周南、召南—齐）→ **`Q379`（豳—陈）** → `Q334`（二雅与颂）→ `Q335`（六舞与「观止矣」）。

**★ 站长杨本文字与注疏本逐字一致**：站长所核杨本作「美哉，渢渢乎！大而婉，險而易行，以德輔此，則明主也」；本库以《春秋左传正义》十三经注疏本（卷三十九）电子本独立复核，**正文逐字相同**。两条独立取得的证据互证，本段用字与断句可视为已定。

**校勘三则（写入 `Q379.modern_note`）**

| # | 项 | 结论与内证 |
|---|---|---|
| ① | **「渢渢」非「渢楓」** | ctext 与维基整理本皆作「渢楓乎」，系重文符号误录；杨本与注疏本皆作「渢渢乎」。**内证**：杜预注「渢渢，中庸之聲」、《经典释文》「渢，扶弓反，徐敷劍反，韋昭音凡」——注与音义皆只释一字而以叠字为文 |
| ② | **断句从杨本** | 本条作「大而婉，險而易行，以德輔此，則明主也」；ctext 断作「……險而易行，以德輔此」，维基整理本断作「險而易．行以德輔．此則明主也」，两本互异。**内证**：杜注「大而約，則儉節易行」，以「儉（險）而易行」连读而与「大而約（婉）」相对 |
| ③ | **《史记》异文并存备考——并得一层新解** | 《史记·吴太伯世家》作「大而寬，儉而易，行以德輔，此則盟主也」。**「儉」一字非《史记》独异**：杜注明言「**『險』當為『儉』字之誤也**」，《经典释文》「險，依注音儉」——杜预所定之正字正作「儉」，《史记》所据本与杜注暗合。故本库正文照录传世本之「險」而于注中标明杜注所定正字为「儉」；读者据此可知此处《史记》**不是「异文」而近于「存正字」**，二者当合观。 |

第 ③ 则是本件在任务书所要求的「并存备考」之上多得的一层——任务书原拟只作「儉／險之异」并存，实则杜注已为此二字定了正俗。

**连带修正**：`Q333.modern_note` 与 `Z101.notes` 中「摘录避开该段」「不作校勘论定」诸语随补录而失实，已一并改写（`Q333` 改为四条次第并注明「至此已无留白」；`Z101.notes` 改为记载校勘经过与两条独立证据）。
