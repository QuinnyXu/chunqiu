## 2. 四题各自的处置

### 2.1 题一 · presence「亲至」首例

**结论：`P_KONGZI` 于 `E274` 标「亲至」／`direct`——本库孔子四条既有条目（`Q179`／`Q252`／`Q261`／`Q262`）皆「相关」，此为其第一条「亲至」。**

**判据（三处会场行动明文，俱在传文，非注家、非后出）**：

1. 「**孔丘以公退**」——携鲁公后退，是与鲁公同在坛上之行动；
2. 「**孔丘使茲無還**揖對曰」——命人当场揖对齐之载书；
3. 「**孔丘謂梁丘據**曰」——与齐大夫当面论享礼。

三处皆合 §7「presence 从严通例」所许之「会、盟」明文（「只有史文明书其人在事发地（会、盟、战、朝、奔、生卒于其地）方标『亲至』」）。

**判据之所不倚——「相」字之训**：传只书「孔丘相」三字。「相」为摄相国之事，抑或会仪之傧相，本库**不断**：《史记》作「孔子攝相事」属 S 层（`Q457`），依 §7 v1.21「注家之说不当经传明文用」，此训不入骨架。**要紧的是：presence 之判不系于此训**——无论「相」作何解，上列三处行动明文都已足；训悬而判不摇。此点已写入 `Q455.modern_note`，以免读者误以为「亲至」是从「相」字推出来的。

**同条另一「亲至」——`P_QIJING`（齐景公）**：经「公會齊侯于夾谷」，传「齊侯從之」「齊侯聞之，遽辟之」「齊侯將享公」，在场明文俱足，标「亲至」／`direct`。

**两处从严不立（本题之另一半，反面同样要留痕）**：

- **晏婴（`P_YANYING`）不挂本条。**《史记·孔子世家》有「左右視晏子與景公」，《左传》夹谷一节**无晏婴之名**。S 层孤证不足以立在场明文——依 §7 presence 从严通例与「后出叙事分层通例」，不为其挂链、不标任何 presence。合并模拟设**反面断言**一条实测此项（`P_YANYING` 不在 `E274` 挂链中）。
- **鲁定公不挂本条**——非因不在场（经、传皆书「公會齊侯」，其人正是会主），而是**其人本库尚未立 `people` 行**。立行属定哀骨干批（`docs/kaoding_kongzi.md` §2.2 甲-3／甲-5 所需），本件不代立、不越批。故本条落成一件「会主不在挂链中」的事目，此系分批之形所致，非判据之失，已在 `Q455.modern_note` 与本节写明，并列入 §7 上报。

**与前置二裁之关系**：待-2（昭二十「女何弔焉」从严「相关」）、待-3（哀十一并条取「亲至」）均已照准，二者所涉事目不在本件范围内（本件只做定十一条），故本件**不动**其数据、不预写其条目。本件之「亲至」与待-3 之「亲至」判据同型（皆有面对面互动明文），可互为参照。
