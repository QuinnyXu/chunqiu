## 6.2 E187 的取号与 reliability 论证

**ID 取 `E187`，避撞依据三项**：① 主表最大号为 `E186`，接续即得；② `data/incoming/` 下除 `fix23` 外无第二批备料，不触 §2.1「并行备料 ID 网段预分配」；③ 退役名单 `E005`/`E006` 已确认不在主表，不涉复用作废 ID。同年 `sort_key` 取 60（该年已用 10/20/25/30/40/45/50），合并模拟已断言不重复。

**`medium` 的三闸论证（依 §7）**：
- **闸一·材料层级**：来源 `G002`《国语·齐语》属春秋记言体当代文献层，既非 `T` 层寓言（裁定4 禁）、亦非 `S` 层无系年追叙（§7 v1.16 通例禁），**不受"不单独立事件"两条禁令约束**，有资格进入后两闸。
- **闸二·系年可推定但非自证**：《齐语》全篇不系年月；其"桓公自莒反于齐"紧接《左传》庄公九年"桓公自莒先入"（前685·E043），问政一段在叙事流中紧承管仲至齐（E046/E154·同年），故事在前685相齐之后、最迟不出庄公十年。**因系年由旁证推定，依 §7 判例明文取 `medium` 而非 `high`**，推算依据已写入 summary。
- **闸三·有独立行动落点与在场明文**：《齐语》「比至，三釁三浴之。桓公親逆之於郊，而與之坐而問焉」（本批新增 Q234）——面对面问对，落点临淄，二人在场明文俱全，非空判无着落之语录。

闸二、闸三依 §7 判例"两条件缺一不可"同时成立，单立成立。

**presence 与 relations**：桓公、管仲据 Q234 明文标「亲至」；**鲍叔牙不挂**——《齐语》问政一段自"亲逆之于郊"以下通篇二人问答，鲍叔无一字在场，依 §7 从严通例宁缺不滥。`relations` **不新增**：`R032`（管仲→桓公·君臣·相·high）已在库，`source_note` 且已载《国语·齐语》，本条不产生新 `rel_type`，依 §6.5 不重复录。
