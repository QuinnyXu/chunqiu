## 一、引擎合一：合并后的结构（清偿 TD-r16-01，裁定 1）

### 1.1 一句话结论
把 r16b 判为「无法复用」的两套状态机（单人 `play/*` 距离驱动、并观 `cplay/*` 按年驱动）**合并为唯一状态机 `player`**；单人＝单轨模式、并观＝双轨模式，**只由注入的 `cfg` 区分**，`cplay` 已删除、`play` 旧函数（`togglePlayback/stepPlayback/announceStation/finishPlayback/stopPlayback`）与 `cplay` 旧函数（`cmpTogglePlay/cmpStep/cmpYearNow/cmpUpdateAt/cmpUpdateMarkersOnly/cmpFinish/cmpStop`）全部退役。`grep` 复核：全库已无这些标识符（仅一处注释提及旧名以志沿革）。

### 1.2 统一引擎的三个部件（app.js）
1. **主钟（`player` 状态 + `playerFrame`）**：与模式无关。核心改动是把 r16b 的「`startTs` 停表法」换成**增量累加时钟**——每帧 `elapsed += min(Δt, 100ms) × speed`。
   - `min(Δt,100ms)` 上限：切后台/长帧回来只补一帧，不突进。
   - `× speed`：速度档（见二）。
   - 暂停＝停 RAF 并 `lastTs=0`；续播首帧 `Δt=0`（不追赶）。
   - 交会自动暂停（`holdUntil`）期间**不推进 `elapsed`**，解除后从原位无缝续行。
2. **控制器**：`playerStart/Pause/Resume/Finish/Stop`，各自转调 `cfg` 的生命周期钩子（`onStart/onPause/onResume/onHoldEnd/onFinish/onStop`）与 `cfg.render(elapsed)`。终点由 `playerFinish` **显式** `render(dur)` 落位（并观也由隐式改显式，见 §四·1）。
3. **beats（交会/中断）**：`cfg.beats = [{key, at, fire}]`（按 `at` 升序）。`playerFrame` 检出跨越（`at∈(prev,elapsed]`）即**精确落位到该刻**（`elapsed=at`，两标记不越过交会点）、`fire()`、`holdUntil=now+1200ms`。单轨模式 `beats=null`（无中断，保持逐段观感）。

### 1.3 两种 cfg
| | 单轨 `singlePlayCfg`（单人地图） | 双轨 `comparePlayCfg`（并观） |
|---|---|---|
| 标记 | 1 枚 `#play-marker` | 2 枚 `cmp.markerA/B` |
| 进度→位置 | 归一化 elapsed → 按**段长（几何距离）**分配的段内推进，逐段 `easeInOut` | 归一化 elapsed → **绝对年** `axisMin→axisMax`；两标记各按年沿己轨插值（`cmpMarkerPos` 段内 `easeInOut`） |
| 段定义 | 相邻站点，段时长 ∝ 空间距离 | 年线性映射；标记在各自轨点间按年插值 |
| beats | 无 | 交会年（a、b **同权**）成组 |
| 字幕 | 到站播报「第 N/几 站」 | 「年份·甲乙在世态」；交会拍换免责字幕 |
| dur（1×基准） | `clamp(1200·(n−1),2000,8000)` | `clamp(span·130,4000,12000)` |

### 1.4 与 r16b「无法复用原因」的逐条对照（如何解决）
r16b §九列出七个「结构不同构」的维度，判为「泛化 ≈ 重写」。r17 的解法是**把差异全部外化进 cfg，主钟只认一个归一化时间**：

| r16b 列的差异维度 | r17 如何吸收 |
|---|---|
| 驱动量：距离 vs 绝对年 | 主钟只产 `elapsed`（ms）。「elapsed→位置」的换算下沉到各 `cfg.render`——单轨按段长表、双轨按 `axisMin+p·span`。主钟不关心语义。 |
| 标记数：1 vs 2 | 标记完全由 `cfg` 持有与摆放；主钟不碰标记。1 或 N 只是 render 内部循环次数。 |
| 「段」定义：站点 vs 轨点年 | 段定义封在 render 内；主钟只给一维 `elapsed`。 |
| 有无绝对年轴/游标 | 年轴游标/年号更新是双轨 render 的副作用；单轨 render 不做。主钟无关。 |
| 生卒态灰置 | 双轨 render 内 `placeMarker` 据生卒灰置；单轨无此维度、不做。 |
| **b 级交会自动暂停** | 抽象为**通用 beats 机制**——`{at,fire}` 列表。单轨传 `null`，双轨传交会年。主钟统一处理「跨越→落位→fire→hold」。**这条正是 r16b 认为最不可复用的「双人独有概念」，现被 beats 泛化吸收，且顺带支持 a 级同权（见三）。** |
| 私有状态字段（segs/lastStation vs lastYear/fired/holdUntil…） | 站序/字幕等私有量闭包在各 cfg 内（`singlePlayCfg` 的 `segs/lastStation`、`comparePlayCfg` 的 `byYear`）；主钟只持 `elapsed/holdUntil/firedBeats` 三个通用量。 |

r16b 末段「将来合并方向」预设的接口（归一化时间轴 t → 若干标记位置 + 中断事件列表 + 段定义作参数注入，单轨是 N=1、中断空、段按距离的特例）**即本轮落地形态**。r16b 要求的「同轮双向回归」已做（见三、四、六）。

## 二、速度与手感（裁定 2、5）

### 2.1 速度档 0.5×/1×
- 工具条各加一枚按钮：单人 `#btn-speed`、并观 `#cmp-speed`，文案「速度 0.5×／速度 1×」。
- **默认 0.5×**，`localStorage` 键 `cq_play_speed`（值 `"0.5"|"1"`）记忆，读写包 `try/catch`（隐私模式静默降级为不记忆，遵 conventions §9.1）。
- 两按钮**共用同一记忆值、互相同步显示**（切一个另一个随之更新；跨视图亦保持——jsdom 实测：并观切到 1× 后进单人地图，`#btn-speed` 显示「速度 1×」）。
- 速度只**缩放每帧 Δt、不改内容时长 `dur`**，故**切档即时生效**（`player.speed` 当帧更新），不打断正在进行的播放。

### 2.2 全局调慢
- `dur` 公式保持旧值作为 **1× 基准**，默认 0.5× ⇒ 运动段耗时恰为旧速的 **2 倍**（观感约旧速一半，落在任务「一半到三分之二」区间）；切 1× 即回旧速。
- 单人秦穆公线（8 站，1× dur=8000ms）实测：0.5× 全程 16.0s、1× 8.0s；单帧最大位移 0.5×=4.42px / 1×=8.82px（0.5× 每帧位移减半，明显更稳）。

### 2.3 「汇合点后突然加速」的复现与修复
- **复现（旧因）**：旧 `cmpStep` 用 `startTs += Δt` 逐帧推进停表来冻结；hold 结束那一帧**落回主流程时漏补了「最后一个 hold 帧→本帧」的间隙**，`elapsed` 会跳一小步；叠加旧版**只有 b 级暂停**、a 级同场密集串（文姜×齐襄公前694–687 七年窗仅占全轴约 18%）无暂停，标记在交会簇里线性疾走——两者合成「到点顿一下、随即窜过一串」的加速感。
- **修复**：增量累加时钟从根上消除停表漏补——hold 期间只是**不累加 `elapsed`**，解除后 `Δt` 照常且有 100ms 上限，**无补偿跳步**；再叠加「a 级同权暂停」（三），交会簇里逐点各停一拍，标记自然慢下来。
- **自验（纯逻辑仿真，镜像 `playerFrame`）**：文姜×齐襄公双轨，相邻帧年份跳跃 >1.2 年者 = **0**（无突进），0.5×/1× 各跑一遍均如此。

## 三、交会显示修正（裁定 3、4）

### 3.1 a 级同权自动暂停（修 III.1）＋ 漏亮根因
- **根因＝检测层到显示层的传递缺失**（与任务书预判一致）：检测器 `detectMeetings` 本就检出 a 级（r16b 已核 14/14），但旧 `cmpStep` 的暂停/脉冲逻辑写死 `if (m.level !== "b") continue`——**a 级同场在播放中既不暂停也不脉冲**，遂「检测通过但标亮不过」。
- **修复**：beats **按交会年成组**（`byYear`），**a、b 同权**触发；`cmpFireMeetingBeat(year, list)` 脉冲高亮**该年全部**交会地、只暂停一拍，并按该年是否含 a 级出「同场／同年同地（相邻记载）／同年同地」字幕＋B3 免责句。
