## 1. 风格立场

**"简帛与青铜"，不是"仿古滤镜"。** 春秋气质来自三样东西：绢帛的底、墨与朱的书写、青铜的线。我们只取材质的色与线条的秩序，不做纹理贴图、不做描边金框、不做毛笔字特效。整体原则：**克制、清晰、留白**；装饰只出现在徽记与图标的线条本身。

### 廿六主角主题色 —— 两级国色系（v1.6 立系，v1.7 楚增一阶，v1.12 卫新家族＋五女主角，v1.14 陈/宋两新家族，v1.15 齐/鲁/晋各增一阶）

**「国色定相、人色定阶、徽记定形」**：**国色**（家族）定色相，**人色**在家族内以深浅分阶（郑另借「青—绿」双相拉开距离），**徽记**形状恒定不变，作个人辨识第一锚点、不随色改。全站人物色（选人卡顶条与徽记、人物子导航、时间线加重、地图轨迹、关系 ego/全景节点、分享卡色签）一律取自 `site/styles.css` `:root` 的 `--p-<id>` 变量，**单点管理**；六家族色为 `--state-<国>`。`site/app.js` 于启动 `resolveProtoColors()` 读入填充，不再在代码内写死色值。

> 地图示意国色（`base_map.svg` 的 `layer-states` 淡色块）是另一套「示意疆域」层，与本节人物国色系**同名不同用、不同源**（如齐示意色为青灰、楚为苍绿），本轮不改；「同源同相」指人物色系内部与关系图阵营，地图重绘留待另议（见 delivery_vision_r14 验收偏差）。

### 3.6 编者层标 `.q-caveat`（v1.14，r21 新立）

史料研究员对某些材料另写有**本库的分层处置说明**，写法是在 `passages.modern_note` **开头**加一段 `【…】`，如夏姬线的 `【归罪话术层·非事实判断】`（巫臣两谏「是不祥人也」、叔向之母「殺三夫、一君、一子」）与 `【P 层舆论材料·不作史实用】`（《陈风·株林》）。前端以 `splitCaveat()` 取出首段【…】，单独成条渲染。

- **位置：引文之前，不是脚注里。** 旧渲染把整条 `modern_note` 拼进 footer（`—— 《来源》 · <全文>`），层标遂夹在长今译中间、且位于原文之下——**归罪话术以正文体量呈现、免责标注以脚注体量呈现，主次恰好倒置**。r21 改为提到 `<blockquote>` 顶部：读者读到「殺三夫、一君、一子」之前，先见「归罪话术层·非事实判断」。这是编纂基调在前端的落点，位置本身即是态度。
- **色：一律暖赭 `#B4652F`，不随所在层色变。** 与 §3.5 层徽标分工明确——**层徽标**（右上小胶囊、随层着色）答「这段引文属哪一层」；**编者层标**（通栏、暖赭、界面 sans 字体）答「本库对该层如何处置」。暖赭是全站界面/编者语态色，故读者一眼即知这是编者的话，不是史料本身。
- **不夺层色**：`.quote.has-caveat` 只把左线**加粗一档**（3px→5px）示「另有编者处置」，左线颜色仍是各史料层原色。初版曾把左线一并改暖赭，自验截图发现那会抹掉《株林》诗歌层的青绿左线——恰恰在最需要分层的条目上让 §3.5 体系失效，遂撤回。现《株林》条呈现为：青绿左线＋青绿淡底＋右上「诗歌」青绿徽标＋顶部暖赭编者层标，P 层与其上两条史料层（朱线朱底）一眼可分。
- **文字一字不改**，只挪位置、去外层【】（容器本身已是标记）；`role="note"`；footer 显剩余今译，不再残留【】。四档宽度（1440/1024/768/390）实测均不截断。
- **通用而非特例**：凡 `modern_note` 以【…】开头者自动生效，现库三条（Q180/Q188/Q193）全在夏姬线；未来任何批次照此写法即自动获得同一呈现，无需改代码。

## 4. 图标语言（15 分类 + 9 徽记）

- 24×24 网格，线描 stroke 1.6，圆头圆角，`fill="none"`，`stroke="currentColor"`——颜色永远由使用处文字色/主题色决定。

## 5.6 全站搜索（v1.3）

- **位置**：页眉站名右侧、主导航之前；680px 下收纳为放大镜图标，点开占整行展开输入框。
- **口径**：纯前端包含匹配（小写化＋去空格），字段间以「|」隔断防跨字段误连；输入防抖 200ms。四组：人物（name/alt_names/姓/氏/名/字）、地点（古名＋今地名）、事件（标题＋摘要＋事发地古今名——搜「临淄」应见发生于临淄之事）、原文（quote_original＋modern_note，白话注多为简体，兼济繁简检索）。

- **字体**：canvas 用系统栈（SHARE_SERIF/SHARE_SANS），letterSpacing 兼容性不齐故逐字绘制。
- **入口**：页脚「生成分享卡 · 复制链接 ·（直接分享）」与反馈行（Issues＋邮箱）相邻；「直接分享」仅在支持 Web Share API 的环境出现，优先携图（canShare files），退化为链接分享。复制链接写入主站 URL，成功 toast 用 N5。
- **对话框**：尺寸切换胶囊、预览、下载 PNG（toBlob）；Esc/遮罩/✕ 关闭，Tab 简易圈定。

**色签改按国色家族计（v1.15，r22）——这是构图承重改动，不是排版微调，勿改回按人计。**

- **旧法**：每主角一枚色签（`tw=26, gap=14`），一行宽 = `40×主角数 − 14`，**随主角数线性增长**。23 主角时 906px，距内框净宽 992px 只余 43px；26 主角时 **1026px**，起点 x = 27——**不但越过内框（x=44）17px，连外框（x=30）也已越出 3px**。r21 曾预警"再加 3 人触框"，r22 实测即已触框。
- **新法**：每**国色家族**一枚圆点（`r=10`，中心距 44），一行宽 = `44×(家族数−1) + 20`。九族现为 **372px**，左右各余 310px。
- **改动的实质是换掉增长源**：由「主角数」改为「**国色家族数**」。新增主角不再加宽一分，唯**新立一个国色家族**才 +1 枚；而家族数增长远慢于主角数（现九族 26 人，且新族须经跨族可辨性实测方能设立，见 §2）。此前每轮加人都在逼近框线、迟早要再撞一次，换源之后这条线才真正稳住。**若日后有人以"点太少、显不出人多"为由改回按人计，即是把这个已解决的问题重新引入。**
- **色序与色值同源 `STATE_FAMILY_VAR` / `familyColor()`**，与首页九分区、关系全景阵营底晕共用同一份，不另写一份（新增国色家族时只改 `STATE_FAMILY_VAR` 一处，三处呈现同步扩展）。现序：齐/鲁/郑/晋/秦/楚/卫/宋/陈，与首页分区序实测一致。
- **不另加人数字样**（Vision 判断，已报备）：分享卡是品牌门面而非数据仪表盘；旧的 23–26 枚小色签本也无人数得清，并未真正承担"计数"职能。且人数逐轮变动，若印在图上会使每轮都需重出分享图。九枚国色点读作一串"印珠"，与「简帛与青铜」语汇相合，作纯装饰色带即可。

**「相关」的措辞分寸（v1.14，Sophia 定，全站执行）**：`相关` 的准确含义是**史文无其在场明文**，不是**史文书其不在场**。站内任何解释性文案（tooltip、aria-label、图例、状态行、凡例）**不得写成或暗示「其实不在场」**。r21 据此改三处旧措辞：地图锚点 aria-label「相关地点，本人不在场」⇒「相关地点，史文无其在场明文」；关于页「怎么读」段「与其相关而本人未到之处」⇒「事与其相关而史文无其在场明文之处」；数据凡例段「事与其相关而本人不在场」⇒「事与其相关，而史文无其在场明文」，并补一句「**「相关」是"史文没说他在"，不是"史文说他不在"**」把分寸显式化。**建议 conventions §6 的 presence 定义（现作「相关＝事件与其相关但本人不在场」）同步订正**，见交付说明上报事项。

**状态行补注（v1.14）**：地图状态行在轨迹句之后，若该人另有「相关」落点，追加一句「另有 N 处相关地点（史文无其在场明文），空心示之、不入轨迹。」——通用于全部人物（现库 17 人触发），使「史文所系之地」与「亲至可考之地」在同一行里可分。**夏姬线是这一句最见分量之处**：状态行读作「亲至轨迹共 2 站，前596 起。另有 3 处相关地点……」，图上郑、晋两实心点连一段虚线，陈（宛丘）、株林、楚（郢）三点空心散在南方——四国皆有其事，史文能确证她在场的只有两处。**这张薄地图不是数据缺口，是内容本身，不得为「好看」而把陈、楚补进亲历轨迹。**
