## 四、异型分野实感（本件考题，全文见 CHANGES §0）

**第五章的异是「一句话怎么说」，第六章的异是「同一串事怎么排」。**

第六章逐节读下来，先撞见的不是异而是**同得出奇**——事之有无几乎节节相合，连各国待重耳之厚薄、居狄「十二年」、惠公「立六年」而战于韩都分毫不差。异全在**排布与归属**：卫排在齐前还是宋后、立卓子的是荀息还是里克、杀怀公在即位前还是后、召重耳入秦的是秦召还是楚送。**这类异不藏在任何一句话里，藏在句与句的关系里。**

落到表上就有一处具体的别扭：本库并陈的单位是 `passage`（一引文挂一事件），而结构之异的单位是**事目之间的关系**，表里没有承载它的位置——本件只能把整段行次引文挂在异之所在那一站，再靠十六条 `summary` 增句把这条异「摊」到相关事目上，**并陈之实由多处注文合成，而非由一处引文承担**。

顺手处：**次第层**在第五章只是陪衬，到第六章成了主力，且证明确有分辨力——无此层则「行次不同」与「事之有无不同」只能笼统判相抵，会把两支高度互证的叙事说成对立。别扭处：**措辞层被迫吸收了专名用字之异**；更根本的是「婢妾／嬖」一处——**同异之判本身悬于未核之字**，规则要求先判同异再分层，此处却是层等着字来定，施行顺序反了过来。

## 五、拿不准处 · 需站长／领队裁定

1. **七条规则压力点**（CHANGES §7 全文）：① 需否为「异之成立与否系于未核之字」增设正交状态标「**悬（待纸本）**」；② 措辞层与「名物用字之异」如何划界（本件倾向后者径归口径句、不入三层）；③ 事实相抵须否区分**硬相抵**与**并存之异**（秦召／楚送可并立）；④ **总括语**（「殺之」）对详叙（「縊于新城」）的证据效力；⑤ 次第层须否补限定「**不系时之记载，其行文次序不径作先后之断言**」；⑥ 一对多时**双向互指的落点规则**；⑦ J 层试点价值不宜以新增事目数衡量（知悉即可）。
2. **本件自定操作口径待核可**：「J 引文文字所涉之事目一律增句；`passage` 级互指只落于异之所在」——取「一律」而非「择要」是为免主观取舍。若领队认为同处不必注，`E087`／`E089`／`E090`／`E092` 四条可撤。
3. **【原簡】隶定栏之自限待核可**：转录本正文后附【原簡】隶定字序一栏，形貌极似「原字」；本件从严视其为**同一转录本之自附材料**、不据以判定某字作某，只用以复核简号字序。建议随 conventions 升号写入口径句之下（此栏是该口径最易被绕过的口子）。
4. **目录名与轮次号不一致**：产出落 `round39_xinian6/`（照任务书字面），交付文档为 r40；`docs/changes/` 归档命名请领队一句话定。
5. **两条修正建议（只报不改）**：① `J001.notes` 之「`url` 未能实测复验」一句可清账（本轮与 r32 两度实测 HTTP 200）；② 建议补立《左传·僖公二十五年》「秦晋伐鄀、围商密」骨架事目——本库该事目**零命中**，补立后《系年》节 12 方可并陈（含 J 独有之「徙之中城」）。
